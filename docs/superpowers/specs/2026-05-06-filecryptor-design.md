# FileCryptor 设计文档

## 概述

FileCryptor 是一个绿色便携的文件加密/解密工具，支持拖拽操作，使用 AES-256-GCM 加密算法，提供图形界面交互。

## 核心需求

- **交互方式**：拖拽文件到 exe 上，弹出 GUI 窗口
- **加密算法**：AES-256-GCM
- **密码输入**：每次手动输入，不存储
- **文件夹结构**：加密/解密文件存放在程序同目录的固定子文件夹
- **实现语言**：Go + Fyne GUI 库
- **目标平台**：Windows（可扩展跨平台）

## 架构设计

### 文件结构

```
FileCryptor/
├── main.go          # 入口，处理拖拽参数，启动 GUI
├── crypto.go        # AES-256-GCM 加密/解密核心逻辑
├── gui.go           # GUI 界面（密码输入、进度条、提示）
├── go.mod           # Go 模块定义
├── encrypted/       # 加密文件输出目录
└── decrypted/       # 解密文件输出目录
```

### 工作流程

1. 用户拖拽文件到 `FileCryptor.exe` 上
2. 程序接收文件路径作为命令行参数
3. 弹出 GUI 窗口，显示文件名，要求输入密码
4. 根据文件扩展名自动判断加密/解密：
   - 无 `.enc` 后缀 → 加密
   - 有 `.enc` 后缀 → 解密
5. 显示进度条，完成后弹出成功/失败提示
6. 输出到对应子文件夹

### 加密文件格式

```
[16 bytes salt][12 bytes nonce][encrypted data][16 bytes GCM tag]
```

## 加密设计

### 密钥派生

- 算法：scrypt
- 参数：N=32768, r=8, p=1
- 输出：256 位密钥
- Salt：每次加密随机生成 16 字节

### 加密过程

1. 生成随机 salt（16 字节）和 nonce（12 字节）
2. 用 scrypt 从 password + salt 派生密钥
3. 用 AES-256-GCM 加密文件内容
4. 写入文件：salt + nonce + 密文 + tag

### 解密过程

1. 读取 salt（前 16 字节）和 nonce（接下来 12 字节）
2. 用 scrypt 从 password + salt 派生密钥
3. 用 AES-256-GCM 解密剩余数据
4. 校验 tag（密码错误会自动失败）

### 安全特性

- 每个文件独立 salt，相同密码产生不同密文
- GCM 模式自带完整性校验，篡改会被检测
- 密码不存储，内存中用完立即清零

## GUI 设计

### 窗口布局

```
┌─────────────────────────────────┐
│         FileCryptor             │
├─────────────────────────────────┤
│  文件：example.txt              │
│  操作：加密                     │
│                                 │
│  密码：[________________]       │
│  确认：[________________]       │
│                                 │
│  [████████████░░░░░░░] 60%      │
│                                 │
│        [ 开始 ] [ 取消 ]        │
└─────────────────────────────────┘
```

### 交互逻辑

1. 拖拽文件后，窗口自动显示文件名和操作类型
2. 加密时需要输入两次密码并确认一致
3. 解密时只需输入一次密码
4. 点击"开始"后显示进度条
5. 完成后弹出消息框提示结果
6. 密码错误时提示重新输入，不退出程序

### 错误处理

- 文件不存在 → 提示文件未找到
- 密码不匹配 → 提示重新输入
- 解密失败（密码错误/文件损坏）→ 提示密码错误或文件损坏
- 输出目录不存在 → 自动创建

## 依赖

- Go 1.21+
- fyne.io/fyne/v2 （GUI 库）
- golang.org/x/crypto （scrypt 密钥派生）

## 打包

使用 `go build` 编译，或使用 `fyne package` 打包成单个 exe 文件。
